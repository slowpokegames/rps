# RPS-5

A 60-card deck: every ordered set of 3 distinct symbols from Rock, Paper,
Scissors, Lizard and Spock.

- `play.html` — play five games with the deck against bots (Showdown, Flank,
  Round Robin, Streak and Classic). Live at https://slowpokegames.github.io/rps/
- `deck.html` — printable deck.
- `src/rps/` — Clojure engine, simulations and deck analysis.
